# Source screen and candidate choice, 2026-10-10

This screen narrows the next action; it is not a general literature review or a priority claim.

| Primary source | Inspected evidence and implication |
| --- | --- |
| [Raupach et al., Physical Review A 105, 042615 (2022)](https://journals.aps.org/pra/pdf/10.1103/PhysRevA.105.042615) | Full text retrieved, setup/methods and results reviewed. Time-stamped trigger validation and rate-dependent efficiency are established. Simply discarding recovery periods does not constitute a new method. Raw run records were not retrieved. |
| [Wayne, Bienfang and Polyakov (2017), institutional record](https://www.nist.gov/publications/simple-autocorrelation-method-thoroughly-characterizing-single-photon-detectors) | Institutional description screened; full-text access unresolved through the inspected DOI route. Autocorrelation characterization is established. A detailed algorithm comparison remains pending if this detector route is resumed. |
| [Koerner et al., Photon Inhibition (2024)](https://arxiv.org/html/2409.18337v1), [author code](https://github.com/lucask07/spad_photon_inhibition) | Observation model, limitations and saturation look-ahead implementation reviewed. Existing code enumerates allowed observation patterns and computes likelihood estimates. Stopping-sensitive uncertainty requires care, but no error in the authors' MLE implementation is established here. Their stated limitations already acknowledge adaptive sampling bias. |
| [Lee et al., arXiv:2610.02644v1 (2026)](https://arxiv.org/html/2610.02644v1) | Full short article inspected. For two known Poisson rates, their sequential deadline rule is an SPRT; the stated mean-time optimality is relative to its achieved error pair. A naive timing/SPRT proposal cannot improve that unchanged problem. |
| [Nitinawarat, Atia and Veeravalli, arXiv:1205.0858v6](https://arxiv.org/pdf/1205.0858v6) | Framework, relation to prior work and optimality scope reviewed. Adaptive experiment selection and finite Bayesian dynamic programming are already established. We did not implement an exposure optimizer and call it new decision theory. |
| [Tudball et al., arXiv:1906.10159v4](https://arxiv.org/pdf/1906.10159v4), [published article](https://doi.org/10.1093/biomet/asac042) | Section 2 and Appendix C inspected: bounded weighting, population moments and relaxed-constraint asymptotic inference. The population idea behind balanced selection bounds is already covered. Reproduce the applicable confidence procedure before claiming superiority. Its [R repository](https://github.com/matt-tudball/selectioninterval) documents logistic-weight OLS/2SLS support, so applying Appendix C here needs an explicit mathematical implementation, not an assumed package default. |

The ordinary balance identity follows directly from the original model's marginal equalities and is absent from the frozen upper-report implementation. This makes it a closer continuation of the current paper than a generic new detector estimator. Its finite conditional test must still be compared fairly with auxiliary-constrained inference.

The public [Quanta Burst Photography repository](https://github.com/sizhuom/quanta-burst-photography) links raw camera data and a dark-frame folder. Public listing access succeeded; individual scene archives range roughly from 0.7 to 2.6 GB. No archive was downloaded or analyzed in this screen. A download link and a code license do not establish raw-data redistribution permission, a calibration budget, stationary illumination, or a spacetime observation bridge. No contact or authentication was required for the listing.
